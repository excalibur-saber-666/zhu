# 论文公式与代码映射表

| 论文内容 | 主要公式 | 对应代码文件/函数 | 一致性说明 |
| --- | --- | --- | --- |
| 3F3L场景、13段显式故障与论文 profile | 3长机、3僚机、600 s、0.02 s、1 s、0.2 m | `stage1_cusum_3f3l_config.m`、`stage1_cusum_default_config.m` | 论文仅对应 `stage1_cusum_3f3l_config('li_style_dense')`。 |
| 共享随机输入与四方法对照 | 同一 IMU、GPS、测距噪声和故障调度 | `main_stage1.m`、`run_stage1_cusum_comparison.m` | EKF、FGO、CUSUM-EKF、CUSUM-FGO复用缓存输入。 |
| 测距模型 | `z = ||p_i-p_j|| + v + b`，`sigma_d=0.2 m` | `run_stage1_cusum_comparison.m` | 偏差只由离线注入器写入；在线检测函数无故障元数据输入。 |
| 独立 alpha-beta 预测 | `d^- = d_hat + d_dot_hat Delta t`；预测残差 | `compute_ekf_cusum_range_weights.m` | 逐边、仅依赖该边当前与历史测距；不依赖已融合位置。 |
| 健康标定与归一化创新 | `S_eff=max(s^2,sigma_d^2+sigma_pred^2,sigma_min^2)`；`xi=(r-mu)/sqrt(S_eff)` | `compute_ekf_cusum_range_weights.m` | 15个有效样本后基线有效；论文 profile 的后续基线自适应增益为0。 |
| 双侧带遗忘因子 CUSUM | `C+`、`C-`、`C=max(C+,C-)` | `compute_ekf_cusum_range_weights.m` | CUSUM-EKF 与 CUSUM-FGO在论文 profile 下都使用该检测器。 |
| 预测器冻结与报警释放 | 冻结距离水平；释放条件为两类条件的“或” | `compute_ekf_cusum_range_weights.m` | 报警时仅受限更新速率；连续释放后清零正负统计量。 |
| 候选软权重 | `w_bar=clip[1/(1+g(E_C+(E_xi)^2))]` | `compute_ekf_cusum_range_weights.m` | 同时使用累计证据与瞬时创新超额，不是解析最优权重。 |
| `per_follower_max`软降权 | 每僚机选 CUSUM 最大的可疑长机边 | `compute_ekf_cusum_range_weights.m` | 原始论文 profile 仅对该主导长机边施加候选软权重。 |
| 报警后选择性隔离 | `eta=0` 仅用于每僚机 CUSUM 最大的报警长机边 | `run_stage1_cusum_comparison.m` | 只阻止异常边写入新帧；其他边保持可用。 |
| EKF加权批量更新 | `R_eff=sigma_d^2/w + u^T P_j u` | `cooperative_range_ekf_update.m`、`cooperative_range_kf_update.m` | 节点GPS更新后先冻结均值和协方差，故批量结果不依赖边遍历顺序。 |
| FGO等权基线 | 单历元位置先验与测距因子 | `factor_graph_centralization.m` | 传统FGO不是滑动窗口，也不启用CUSUM。 |
| CUSUM-FGO加权测距因子 | `r_tilde=eta*sqrt(w)/sigma_d*(||p_i-p_j||-z)` | `factor_graph_sliding_window.m` | `sqrt(w)/sigma_d` 仅作用一次；确认报警的边不写入新帧。 |
| 10帧窗口和SINS相对位移因子 | 位置先验、相邻帧运动、帧内测距残差 | `factor_graph_sliding_window.m`、`run_stage1_cusum_comparison.m` | 超长时直接移出最早帧；当前实现无 Schur 补边缘化先验。 |
| 50次统计和性能指标 | 3D误差、RMSE、CDF95 | `run_li_style_paper_experiment.m` | 只有实际运行生成的 `li_style_dense` 结果可用于第4章图表和数值结论。 |

## 明确排除的路径

- `compute_signed_cusum_edge_weights.m` 的位置先验创新路径只在 `prior_innovation` 检测模式下使用，不属于当前论文 profile。
- `li_style_dense_tuned`、`li_style_dense_fgo_recovered` 与默认关闭的IMU预积分均为保留研究变体，不属于当前论文图、表或50次统计。
