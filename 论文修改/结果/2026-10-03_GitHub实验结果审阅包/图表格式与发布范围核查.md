# 图表格式与发布范围核查

用户指定上传两阶段的报告、汇总 CSV 和主要图表，随后要求删除图片 PDF。当前审阅包按该范围收录材料，不包含原始 MAT、NPZ 缓存、逐历元数据、Word 原稿或参考论文。

已删除本轮九组图的 PDF；保留九组 SVG 与九组 600 dpi PNG。保留文件的 SHA256 与删除前一致，既有图像阅读检查仍适用于这些未变更的文件。

两个绘图入口已取消 PDF 导出。分别运行导出路径的短验证，只生成 PNG/SVG；两阶段全部九组实际图的物理尺寸、分辨率、SVG 文字与导出完整性核查通过。13 项统计测试重新通过，实验数据和统计实现未修改。

通用 nature-figure 预检查器默认要求 PDF 导出及 PDF 字体配置，在两个脚本上各报告这两项默认要求失败。用户明确要求不生成 PDF，因此这四项记录为用户指定格式的例外；其余失败为零。SVG 保留可编辑文字，PNG 为 600 dpi。此说明不把通用默认检查结果描述为零失败。

压缩包内报告与历史验收 JSON 是既有实验完成记录。其“未推送 GitHub”和 PDF 属性描述当时状态；本次发布及取消 PDF 属后续授权，不覆盖原始验收记录。现行格式验证见两个阶段的 `validation/png_svg_format_validation.json` 和更新后的 `validation/figure_exports.json`。

本包便于核查报告、聚合表和图表之间的一致性；完整独立复算仍需要本地原始数据与执行快照。E3 的健康误隔离和恢复超时、E4 的硬件 / 1 Hz 适用边界及 E5 的基准场景限制均保留。
