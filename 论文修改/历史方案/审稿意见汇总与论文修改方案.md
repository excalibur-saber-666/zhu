| 报警阈值 h | 5.0 | 健康误报警和故障检测延迟的选择依据 |
| 报警解除阈值 | 1.2 | 与报警阈值形成滞回 |
| 连续确认 / 连续解除历元数 | 2 / 3 | 防止瞬时波动引起状态切换 |
| 归一化创新门限 / 解除创新门限 | 4.0 / 1.0 | 接受更新与近正常状态判定 |
| 权重死区 / 衰减增益 / 最小权重 | 1.50 / 0.50 / 0.10 | 连续降权程度及信息保留 |
| alpha-beta 增益 | 0.30 / 0.05 | 预测跟踪性及异常吸收风险 |
| 预测不确定度标准差 | 0.80 m | 创新归一化尺度的组成 |
| 标定样本数 / 标定后自适应增益 | 15 / 0 | 启动阶段和固定健康基线 |
| 预测器冻结门限 | 1.00 | 何时停止由可疑测距更新距离水平 |
| 位置滑窗长度 / 运动标准差（ENU） | 10 帧 / 2、2、4 m | 时序约束与计算负担 |

**必做 E1 只聚焦报警阈值 h 与漂移参数 κ：**建议以 3 个 h 水平 × 3 个 κ 水平的小型二维网格起步，包含无故障健康场景和固定故障评估场景。具体水平在运行前固定；只有网格不足以判断趋势时再补局部点，不扩展成全部参数的大规模扫描。

λ、确认历元数和最小权重仅作为可选的少量单因素补充；若 h–κ 结果已经充分回应审稿意见，不要求逐项追加，也不与 h–κ 或场景扩展做高维组合。

E1 的目的固定为敏感性/鲁棒性分析，保留论文主参数 h=5、κ=0.5，不用正式评估结果重新寻优。冻结网格为 h={3,5,7}、κ={0.25,0.5,0.75}，其余参数、两类场景、seed 1–50 和统计窗口不变；中心点复用 E3。仅评估主方法 CUSUM-FGO，不把四方法重复乘到网格。若今后另行批准重新选参，calibration seeds 与 evaluation seeds 必须严格分离；本轮不执行重新选参。参数依据表述为误报警、检测延迟和定位性能的经验折中，不表述为理论或全局最优。

本轮 E1 只评估主方法 CUSUM-FGO，不追加 CUSUM-EKF 网格。与 h、κ 无关的基准方法结果不在网格重复执行；中心点与同 seed 实际输入核查后复用。

**输出：**参数及选择依据表；阈值—漂移参数的定位误差、误报警率和检测延迟图或表；对变化趋势与适用范围的讨论。若健康创新不独立或不服从设定分布，不直接套用未经验证的经典 CUSUM 理论阈值结论。

### 4.3 编队规模与 NLOS 强度：R2.2

保留 3F3L 作为复现基准，再增加至少一个较小和一个较大编队。候选为 2F3L、3F3L、5F3L；具体节点位置及规模须先检查数据支持、通信距离和几何约束，不能仅改节点数量。

E2a 与 E2b 为两个独立实验，不做“所有规模 × 所有 NLOS 强度”的全因子组合：

1. **E2a：规模实验。**固定噪声模型与基准 NLOS 条件，仅比较小、基准、大编队；记录有效边数量、通信距离、连通性、几何可观性和异常边比例，避免将规模变化与几何退化混为一谈。
2. **E2b：强度实验。**固定 3F3L、几何布局与故障时段，仅比较弱、中、强 NLOS；说明是在相同模型下缩放偏差，还是改变分布参数，避免同时改变持续时间与发生率。

若小、基准、大与弱、中、强各取 3 水平，两组实验共用“3F3L + 基准 NLOS”结果，形成 5 个不同的场景配置，而非 9 个规模—强度组合。各场景比较现有四方法，不再乘上全部参数网格或可选消融。

已有随机 NLOS 使用 0.60×N(3,0.6²)+0.40×N(6,1.0²)，截断至 1–8 m，每段抽取一个偏差并保持。它不是“每个采样时刻独立抽取 NLOS 偏差”，应在方法与实验描述中写清。

四方法在同一种子下共享轨迹、IMU 噪声、位置观测、测距噪声和 NLOS 实现。不同规模时无法保证观测维度完全相同，应说明如何控制可比的轨迹、噪声和故障比例。

**输出：**全体僚机的定位统计、编队整体统计、规模和强度趋势。若只验证单边故障假设，不扩大为任意多边干扰的泛化结论。

### 4.4 选择性隔离、误隔离与恢复：R2.3

现稿已说明报警确认后停止异常边进入新帧，并保留历史因子直到滑出窗口，但缺少恢复条件、健康边风险和相应结果。

**适用边界必须在 Discussion 写明：**当前实验和选择性隔离主要验证“同一 follower 同一时刻最多一条主要异常 leader-ranging edge”。同一 follower 同时出现多条严重异常边时的有效性尚未充分验证。本轮不为此重新设计算法，也不把多严重异常边实验列为必做项；以明确边界和限制回应，避免过度泛化。

方法部分应逐步解释：

- 初始化与健康标定如何进行；校准样本不应依赖离线真值标签选择。
- 双侧统计、软降权、预测器冻结和连续确认之间的先后顺序。
- 对每个僚机如何选出最可疑长机边；报警不等于将所有边同时删除。
- “检测报警状态”和“该边实际停止准入状态”的区别。
- 当前实现的解除判据：满足“CUSUM 低于解除阈值且创新在门限内”，或满足“创新连续接近正常”，达到规定连续历元数后解除报警并清零累计统计。
- 解除后何时实际恢复新测距因子；还需检查是否被同僚机其他边的选择状态影响。
- 历史异常因子仅随窗口滑出，并非在报警后立即追溯删除。
- 备用 recovered profile 的反向创新复位当前关闭，不能作为主 profile 已使用的恢复机制写入论文。

建议选取含故障开始、持续、结束及后续转弯的代表性边，绘制“原始偏差或离线故障标签、归一化创新、正负 CUSUM、权重、报警状态、实际准入状态”时间序列，并展示同僚机健康边作为对照。

离线评价至少包括：

| 指标 | 拟定统计对象与注意事项 |
| --- | --- |
| 故障检测率与漏检事件数 | 按真实故障事件统计，说明可匹配的边及时间范围 |
| 健康误报警率（false alarm） | 健康边发生报警的频率；明确边历元分母或单位时间事件定义 |
| 健康误隔离率（false isolation） | 健康边实际停止新因子准入的频率；与误报警分别报告 |
| 检测延迟（detection delay） | 故障开始到首次有效报警；漏检不能以零延迟计入 |
| 隔离延迟（isolation delay） | 故障开始到实际停止新因子准入；与检测延迟分别统计 |
| 恢复延迟（recovery delay） | 故障结束到稳定恢复该边新因子准入 |
| 恢复失败率（recovery failure rate） | 在预设后续观察期内未恢复的事件比例，不能只统计成功恢复事件 |
| 约束损失与误差影响 | 准入边数量、受影响僚机误差与历史因子滑出过程 |

**验收：**能回答“是否隔离了健康边、隔离持续多久、何时恢复、恢复失败多少、几何约束损失如何影响误差”；不提前使用“无误报警”或“立即恢复”等绝对表述。

### 4.5 四方法计算性能、收敛与实时性：R2.4

E4 统一比较 EKF、FGO、CUSUM-EKF 和 CUSUM-FGO 的单次在线更新耗时。四方法使用同一硬件、场景、输入和计时口径；既有三种规模各 10 seed 独立串行计时，未使用并行 E2 的局部计时推断实时性。

实施修正：现有 E2 是并行运行且只保存局部计时，不能作为正式 E4 的完整在线耗时。E4 单独在一个 MATLAB 进程、一个计算线程中测量既有 2F3L/3F3L/5F3L，seed 1–10，关闭绘图和导出；不新增轨迹或参数矩阵。同一配置的四方法保持共同输入，预热不计入正式统计。必须同时报告 algorithm-specific runtime（方法处理部分）与 end-to-end online update runtime（1 s 中的 50 次 SINS 传播加一次完整协同更新），排除离线真值/故障注入与日志、文件写入。1 Hz 的 1 s 预算判断采用后一种口径。

当前代码已有更新子过程计时、Gauss–Newton 迭代数、最终步长和收敛状态记录。静态核对显示现有计时起点在检测与加权之后，不能直接作为包含检测、观测融合和反馈的完整在线更新耗时。后续只按需要补齐计时和日志，不改变核心算法。

| 需要补充的内容 | 拟报告项目 |
| --- | --- |
| 环境与公平性 | CPU、内存、操作系统、MATLAB 版本、线程设置；同硬件、相同输入、相同运行条件 |
| 统一计时范围 | 位置观测处理、检测与加权、建图或滤波更新、求解、协方差提取与反馈，直至导航输出 |
| 四方法耗时 | 每种方法的均值、中位数、P95、P99、最大值与超过 1 s 预算比例 |
| 图方法收敛 | FGO、CUSUM-FGO 的平均与最大迭代次数、最终步长、达到最大迭代数比例、失败与未收敛次数 |
| EKF 类方法 | Gauss–Newton 迭代项标为不适用，不以 0 表示“优于优化器收敛” |

建议计算性能表的基本列为：方法、平均更新耗时、P95、P99、最大耗时、超预算比例、平均迭代数、最大迭代触顶比例、失败或未收敛次数。收敛相关列对 EKF 类方法写“不适用”。

当前的位置滑窗求解器停止规则为最多 30 次迭代，增量无穷范数小于 1e-5 时停止，使用 QR 求解。其他图方法的停止规则以其实际实现为准，不能直接套用主方法阈值；失败、数值异常和未收敛分别记录，不只汇总成功样本。

性能计时关闭绘图、文件导出和非必要控制台输出，说明预热与重复方式。共享的 50 Hz 惯导传播若另行计时，应明确说明并计入周期总预算，不能把某个子过程耗时等同于完整在线处理代价。

**输出：**四方法统一计算性能表与图方法收敛统计。结论限定为“在当前测试硬件与 1 Hz 更新频率下具备在线运行可行性”，且须由测得的预算与超时比例支持；不扩展为“满足机载硬实时要求”。

### 5.3 全部 follower 与 formation-level overall 统计

正式返修主表至少报告 Follower 1、Follower 2、Follower 3 和 formation-level overall，指标包括 Maximum、Mean、CDF95，并补充三维 RMSE。更大编队按其全部 follower 汇总。健康段与故障段分开时，说明对应时间范围。

1. 对每种方法、每个 Monte Carlo seed，先计算各 follower 的指标。
2. 在同一 seed 内汇总全部 follower 与时刻形成 overall，说明各 follower 的权重和样本范围。overall CDF95 从对应误差样本分布计算，不能用各 follower 的 CDF95 算术平均替代。
3. 对现有 50 个 seed 的各项指标汇总均值和离散程度，必要时给区间；方法比较使用同 seed 配对。新增场景的 seed 数和统计方式在运行前固定并明确报告。
4. 逐 seed 的 Maximum 再汇总，与全部 seed、全部时刻的全局最大值是不同统计，表头需明确。合并 CDF 作为描述性结果可以保留，但不能把同一时序中的数万个 epoch 当作独立试验进行统计推断。
5. 优先从已有保存结果补全 follower 和 overall 表，避免只为扩展主表重复执行同一组完整仿真。

6. formation-level 同时报 pooled overall 与 follower 等权 macro-average，先在每个 seed 内对各 follower 的同一指标取平均。macro CDF95 / Maximum 分别是各 follower 分位数 / 最大值的均值；等权汇总不能消除不同规模的角色、几何或故障暴露差异。本项已在 E2 正式结果完成。

**验收：**主表覆盖全部僚机及整体，统计以 seed 为独立重复单位，指标定义、合并分布和重复间波动分别写清。
