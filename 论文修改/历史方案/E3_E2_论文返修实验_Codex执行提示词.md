## 三、E3：选择性隔离、误隔离与恢复

### 目标与范围

E3 应回答：算法是否会错误报警或隔离健康测距边；真实异常发生后多久能够检测和隔离；异常结束后能否稳定、及时恢复测距因子准入；这些状态变化对可用约束和定位误差有什么影响。

根据实际代码核对预测器更新与冻结、双侧 CUSUM、连续软降权、报警确认、实际因子隔离、报警解除和重新准入逻辑。特别区分停止新因子准入与历史因子随滑窗退出，不能将两者混写成“报警后立即删除所有异常因子”。实验与论文描述应以真实实现为准，不得为了与现有文字一致而静默改变算法行为。

至少覆盖以下两类场景：

- **基准 NLOS 场景：** 优先复用现有 3F3L 基准场景及其随机机制，观察健康 → 故障 → 检测 → 实际隔离 → 故障结束 → 恢复或重新准入的完整过程。
- **健康机动压力场景：** 不注入 NLOS，保留正常传感器噪声、飞行、转弯和机动，直接检验正常机动产生的 prediction innovation 是否触发 false alarm 或 false isolation。

健康机动场景必须先做有效性检查：记录 leader–follower 真实距离、距离变化率及其变化，确认运动确实使测距预测器面临健康动态变化。当前运行器把相同姿态和速度赋给各无人机，共同转弯未必明显改变机间距离；这一静态发现不代替实际轨迹检查，也不能仅凭存在转弯就宣称完成动态压力验证。若原轨迹缺少相对距离变化，使用独立、默认关闭的场景配置增加一个幅度合理的相对机动或速度变化，保留通信与几何条件，不能为了触发误报警而任意放大机动。

健康场景保留正常的在线初始化和标定流程；不要用故障真值标签控制检测器标定、冻结或重置。预先固定启动期、正常飞行期、机动期及后续观察期，分别报告统计范围。原则上只补一个有效的健康机动场景，不扩展为大规模轨迹组合。若以后用于 E1，可复用相同场景定义；本轮不顺带运行 E1。

当前方法主要验证 **同一 follower 同一时刻最多存在一条主要严重异常 leader-ranging edge** 的情况。同一 follower 同时多条严重异常边不作为本轮必须解决的问题，不为此重构核心算法。

### 证据与统计要求

实验输出必须足以独立复算和核查：fault detection / missed event、false alarm、false isolation、detection delay、isolation delay、recovery delay 和 recovery failure rate。必要时分析有效测距约束数量及其与定位误差的关系。

false alarm 与 false isolation 必须分开定义；detection delay、isolation delay 和 recovery delay 必须分别统计。正式运行前把下表中的判据、时间口径与分母写入冻结的实验配置或统计说明，不按结果调整。

| 项目 | 必须明确的口径 |
| --- | --- |
| 故障事件与检测 | 以 seed、场景、稳定的边 ID 及事件序号/起止时间唯一标识事件；定义故障区间端点、检测窗口，以及检测指首次阈值越界还是 confirmed alarm。两种状态都保留日志，不能混用 |
| False alarm | 同时报健康边上新误报警事件数、正常可观测时长，以及健康 edge-epoch 的报警占用比例；若排除启动期，必须统一说明排除规则和数量 |
| False isolation | 依据本应可用的健康测距是否因异常策略而被停止实际准入统计，报告事件数和健康 edge-epoch 占用比例；不能仅凭 alarm 标志认定已隔离，也不能把自然缺测或超距记为误隔离 |
| Detection / isolation delay | 分别从故障开始计到检测时刻和实际停止新因子准入时刻；秒为主，同时保留更新历元。故障前已处于报警或隔离状态的事件单列，不能当作 0 延迟检测成功 |

## 四、E2：编队规模与 NLOS 强度泛化

E3 完成后实施 E2。E2a 与 E2b 相互独立，不做规模 × 强度全因子组合，不与参数敏感性或可选消融组合。

### E2a：改变编队规模，固定基准 NLOS 条件

保留 3F3L 基准，在现有数据、轨迹、通信及测距结构支持的前提下增加一个较小和一个较大编队。2F3L、3F3L、5F3L 为优先候选，最终配置以实际项目结构与几何合理性为准。

不能仅机械修改 follower 数量后直接比较。自行检查并记录各规模下的测距拓扑、有效边数量、通信距离、连通性、几何条件、每个 follower 的可用测距约束和 NLOS 故障比例，避免把规模变化与明显几何退化或非法配置混淆。

固定噪声模型与基准 NLOS 条件，尽量保持轨迹、故障比例和测距条件可比。使用稳定的 follower/leader 身份及边 ID，并记录它们与各规模全局节点编号的映射，避免规模改变后故障被错误注入其他类型的边。预先固定跨规模的故障映射，记录受影响 follower 比例及候选 leader–follower 边的故障 edge-epoch 比例；无法完全匹配的观测维度、故障比例或几何差异应明确说明，并用于解释结果。

几何检查使用位置真值作离线诊断，报告所采用的局部几何秩、条件指标或等价检查及时间范围，不把简单连通性等同于三维可观性。若原仿真假定全连接、没有通信距离上限，应明确说明并报告距离范围，不虚构已验证的无线通信能力，也不在看过结果后补设筛选阈值。

使用现有四种方法：**EKF、FGO、CUSUM-EKF、CUSUM-FGO**。同一场景、同一 seed 下，四方法必须共享配对的轨迹、IMU 噪声、位置观测噪声、测距噪声和 NLOS realization。

### E2b：固定 3F3L，只改变 NLOS 幅值强度

固定飞行轨迹、几何结构、噪声模型、NLOS 发生时段及持续时间，设置 weak / baseline / strong 三档强度。

以当前项目基准配置为准核对 NLOS 模型。现有方案记录的基准为 0.60 × N(3, 0.6²) + 0.40 × N(6, 1.0²)，截断至 1–8 m，且每个 NLOS 段抽取一次偏差并在段内保持。不得将段内固定偏差擅自改为逐 epoch 独立抽样；如代码与该记录不一致，记录真实实现及影响。

采用明确且可复现的幅值变化规则。优先对每个 seed、每个事件仅抽取一次基准截断偏差 b，再令 b_weak = c_weak × b、b_baseline = b、b_strong = c_strong × b，其中 0 < c_weak < 1 < c_strong，具体系数在正式运行前冻结。缩放后相应支持范围为 [c, 8c] m；若又截回 [1, 8] m，就不再是纯幅值缩放，因此不得无说明地二次截断。段内仍保持固定偏差。

不得同时改变发生率、事件边、持续时间和幅值，导致无法解释 NLOS intensity 本身的影响。各方法输入保持配对，跨强度档位保留可核查的共享事件与噪声关系。仅设置相同 seed 不足以证明输入一致：缓存或以独立随机流生成共同输入，检查实际数组或摘要，避免不同代码分支改变随机数消耗顺序。

### E2 证据与统计要求

保存足够完整的原始结果、配置与随机种子，而不仅是最终汇总表。输出全部 follower 和 formation-level 的定位性能，比较不同规模及不同强度下四方法的变化趋势。

定位指标至少包含 **Maximum、Mean、CDF95 和 3D RMSE**。以 ENU 三维位置误差范数 e 为基础，Mean = mean(e)，3D RMSE = sqrt(mean(e²))，Maximum 为最大 e，CDF95 为 e 的第 95 百分位；记录采样范围、分位数算法、启动期及缺失值处理。

每种方法、每个 seed 必须同时输出以下三层指标，不能仅保存原始值而省略 macro-average 汇总：

1. **Follower-level：**逐一保存全部 follower 的四项指标和有效历元数。
2. **Formation pooled overall：**在同一 seed 的固定评价范围内合并全部 follower 的有效误差样本，再计算四项指标；说明各 follower 的实际样本权重。
3. **Follower 等权 macro-average：**对同一 seed 内各 follower 的同一指标 M 计算 M_macro = (1/F) × Σ M_f，再跨 seed 汇总。macro CDF95 必须标为“各 follower 第 95 百分位的均值”，macro Maximum 为“各 follower 最大误差的均值”，都不能解释成整体第 95 百分位或整体最坏误差；整体最坏误差由 pooled Maximum 单独保留。

当各 follower 的有效历元数相同时，macro Mean 与 pooled Mean 相等；macro RMSE、macro CDF95 通常与相应 pooled 指标不同。等权平均可避免有效样本数量不同带来的隐含加权，但不能消除规模变化引起的几何、角色或故障暴露差异。某 follower 或整次运行失败时，必须报告失败及缺失情况，不能删掉该 follower 后仍标为“全编队等权结果”。

正式 Monte Carlo 的 seed 集合与重复次数应在正式运行前确定并记录。小规模调试用于检查可运行性、日志和资源，不用于挑选有利 seed、调参或按效果增减样本。先计算每个 seed 的指标，再汇总均值及离散程度或区间；方法比较使用同 seed 配对。不把同一次仿真的相关时序样本当作独立重复。失败、异常和数值问题不得静默删除；报告请求运行数、完成数、失败数、有效配对数及原因。

E3 的 3F3L 基准 NLOS 与 E2a/E2b 的共同基准，在代码、配置、seed、输入及评价窗口完全一致且原始日志足够时只运行一次、复用结果。E2a 三档规模与 E2b 三档强度共形成五个唯一配置；新增健康机动场景单列。旧结果只有满足上述可比性与复算条件才能复用，否则在独立目录重跑，不能覆盖旧结果。

### E2 验收标准

- **E2a：** 能回答编队规模变化时各方法性能如何变化、CUSUM-FGO 的趋势是否稳定，以及测距几何和拓扑变化对解释的限制。
- **E2b：** 能回答 NLOS 从弱到强时各方法性能如何变化、CUSUM-FGO 的相对优势和适用范围如何变化，不预设结果必须单调或本方法始终最优。
